# Game specs

One file per game, named by its id: `sketch-battle.md`, `codenames.md`, `secret-hitler.md`.

Each spec covers: rules, setup, turn flow, scoring formulas with worked examples, edge cases (each becomes a test), settings for `config.ts`, UI flow for phone and PC, learn-controls tour steps, and the rules card.

A game is not built until its spec exists here. Create its folder with `pnpm new-game <id> "<Name>"` (see docs/PROJECT.md, Code practices).
